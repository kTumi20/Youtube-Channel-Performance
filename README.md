# Youtube Channel Performance Inntelligence Dashboard (11 Aug 2025 - 31 Oct 2025)
A dashboard that will analyse the performance of a startup reaction YouTube channel over the course of 3 months.

## Important Questions

### Creating KPIs
Which video generated the most views?  
What is the average watch time per video?  
What is the click-through rate (CTR)?  
How many subscribers have been gained per upload?  

### Product-Market Fit Signal Indentifiers
Between longer or shorter videos, which ones retain viewers better?  
Which title/thumbnail style impacts CTR?  
Which video formats get more engaement?  

### Posting Optimization
Does time the video is uploaded affect views?  
How quickly do videos gain views after posting?  
Are there early trends in audience activity timing?  

### Channel Discovery
How do viwers find the channel?  
  Suggested videos  
  Browse features  
  Direct or unknown  
  Other YouTube features  
  External  
  Others  

Which source generates the longest watch time?  
Which source generates the most views?  

## YouTube Content Intelligence Dashboard

The dashboard investigates:

* Viewer engagement trends
* Traffic source efficiency
* Content retention signals
* Upload performance patterns

## Dataset

* Aug 11 — Oct 31 2025
* 6 uploads
* Bi-weekly posting cadence
* Metrics exported from YouTube Studio

## Key Skills Demonstrated

* Data Modeling
* DAX KPI Design
* Insight Communication
* Dashboard UX Design
* Digital Marketing Analytics
